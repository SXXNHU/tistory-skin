# Tistory Skin — 개발 가이드

**QUIET EDITORIAL** — hELLO 4.10.6 기반 커스텀 디자인 레이어.
루트 경로(`/`)는 **PLEX 랜딩**(Perplexity Blog 스타일)으로 대체됩니다.

## 📁 프로젝트 구조

```
tistory-skin/
├── src/
│   ├── skin.html      ← 🚀 스킨 HTML (2,137줄)
│   └── skin.css       ← 🚀 스킨 CSS (7,237줄)
│
├── blog-assets/
│   └── lottie/
│       └── playground.json    # Lottie 애니메이션 데이터
│
└── package.json
```

티스토리 스킨은 **단일 HTML + 단일 CSS**만 지원하므로 파일을 나누지 않고
`src/skin.html`, `src/skin.css` 두 개만 직접 편집합니다.

---

## ⚡ 배포 방법

1. `src/skin.html`, `src/skin.css` 수정
2. Tistory 관리자 → 꾸미기 → **스킨 편집** → HTML/CSS에 각각 붙여넣기 → **저장**
3. 저장 후 블로그를 새로고침해 반영됐는지 확인

> ⚠️ 저장이 실패해도 화면상 티가 잘 나지 않습니다. 저장 후 실제 페이지에서
> 변경한 클래스명이 보이는지 한 번 확인하세요.
