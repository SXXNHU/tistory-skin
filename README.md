# Tistory Skin — 개발 가이드

## 📁 프로젝트 구조

```
tistory-skin/
├── src/
│   ├── skin.html      ← 🚀 스킨 HTML (2,356줄)
│   └── skin.css       ← 🚀 스킨 CSS (7,948줄)
│
├── blog-assets/
│   └── lottie/
│       └── playground.json    # Lottie 애니메이션 데이터
│
└── package.json
```

티스토리 스킨은 **단일 HTML + 단일 CSS**만 지원하므로 파일을 나누지 않고
`src/skin.html`, `src/skin.css` 두 개만 직접 편집합니다.

파일 안에는 아래와 같은 배너 주석으로 섹션이 구분되어 있습니다.

```
<!-- ============================================================
  📁 SECTION : 온보딩 랜딩 페이지 HTML
  📋 DEPLOY  : skin.html → <body> 바로 아래, #loader 위
  📝 NOTES   : 루트('/') 진입 시에만 표시
               ...
============================================================ -->
```

에디터에서 `📁 SECTION` 으로 검색하면 섹션 사이를 빠르게 이동할 수 있습니다.

---

## ⚡ 배포 방법

1. `src/skin.html`, `src/skin.css` 수정
2. Tistory 관리자 → 꾸미기 → **스킨 편집** → HTML/CSS에 각각 붙여넣기
   (또는 꾸미기 → 스킨 변경 → ZIP 업로드)

## 📌 자주 수정하는 부분

### 온보딩 커스텀
- **타이핑 단어 변경**: 온보딩 스크립트 섹션 → `var WORDS = [...]`
- **수강 시작일 변경**: 온보딩 스크립트 섹션 → `var START_DATE = '2025-09-06'`
- **히어로 텍스트**: 온보딩 랜딩 페이지 HTML 섹션 → `.onboarding-hero`
- **배경 비디오**: 온보딩 랜딩 페이지 HTML 섹션 → `src="YOUR_VIDEO_URL_HERE.mp4"`
- **카테고리 카드**: 온보딩 랜딩 페이지 HTML 섹션 → `.onboarding-cat-grid` (아이콘, 링크, 글 수)

### 사이드바 커스텀
- **소셜 링크**: 사이드바 섹션 → `.sb-social` (GitHub URL, Email 주소)
- **프로필 문구**: 사이드바 섹션 → `.sb-profile-desc`
- **소개**: 사이드바 섹션 → `.sb-status` (직책 등)

### 스타일 커스텀
- **온보딩 색상/레이아웃**: `src/skin.css` 온보딩 랜딩 페이지 스타일 섹션
- **사이드바 색상**: `src/skin.css` 사이드바 스타일 섹션
- **포스트 목록 스타일**: `src/skin.css` 목록 / 아티클 섹션
